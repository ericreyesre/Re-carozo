Re-Carozo es un sistema de secado solar automático e inteligente diseñado para el procesamiento de carozos (cuescos de frutas).
Mediante una estructura que capta y concentra la energía solar, permite elevar la temperatura y generar condiciones favorables para el proceso de secado.
El proyecto cuenta con una plataforma web informativa para conocer su funcionamiento y una herramienta de gestión desarrollada en Google Sheets, que permite supervisar y administrar el proceso de secado.
